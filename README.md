# Recetario

Primer producto real creado con SOR: un recetario personal, local y adaptable a móvil.

## Propósito

Ayudar a guardar, encontrar y cocinar recetas propias sin depender de una cuenta ni de una conexión permanente.

## MVP acordado como punto de partida

- Crear, consultar, editar y eliminar recetas.
- Ingredientes estructurados y pasos ordenados.
- Porciones, tiempos, etiquetas y favoritos.
- Buscar por nombre, ingrediente o etiqueta.
- Filtrar recetas y conservarlas localmente.
- Exportar e importar una copia de seguridad JSON.
- Interfaz accesible y cómoda en móvil y escritorio.

No incluye todavía cuentas, nube, colaboración, nutrición, lista de compras, planificación semanal, imágenes ni generación mediante IA.

## Estado

El proyecto y su bóveda SOR están inicializados. La implementación vive en el ciclo activo registrado en `memoria/temporal/`.

Para abrir la memoria en Obsidian, selecciona exactamente la carpeta `memoria` de este proyecto.
